# Task Assessment (Job Confirmation Workspace)

Yahan hum job/task ko **proper structure** ke saath complete karenge.

## Kaise use karein
Har task ke liye:
1. Task document ka content (requirements/acceptance criteria) paste/summary yahan add karna
2. Repo me changes implement karna
3. Verification/notes (tests/build + expected behavior) update karna

## Folder structure (recommended)
Abhi main base scaffold bana raha hoon. Main tasks aane ke hisaab se sub-folders/files create karunga:

- `introduction/` (context + constraints)
- `frontend/` (UI-related tasks)
- `backend/` (API/business logic tasks)
- `blockchain/` (smart-contract / chain tasks)
- `web3/` (wallet/connect/integration tasks)
- `ai/` (AI features/tasks)
- `qa/` (QA tasks + bugfix notes)
- `design/` (UI/UX/design artifacts)

## Next step
Aap pehla task ka content/requirements yahan paste kar dein (ya screenshot), main usko is folder me map karke implementation start kar dunga.
