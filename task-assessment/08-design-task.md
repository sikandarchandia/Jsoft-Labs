# Task 8 - Design Task: Dashboard (3 variations)

## Requirements
- Fresh dashboard design using UI principles (hierarchy, usability, consistency)
- At least three variations (styles / states / sizes)

## Implemented
Route: `/dashboard` in the demo frontend.

Switcher at the top:

1. **Classic** — Light sidebar, KPI cards, bar chart, activity feed, data table. Desktop-first, consistent spacing and labels.
2. **Modern** — Dark glass / gradient command center. Strong visual hierarchy with large KPIs and live feed.
3. **Compact** — Mobile-first stacked cards, list rows, bottom nav. Same data, smaller density.

Shared mock data: `src/data/dashboardData.js`

## How to view
Open http://localhost:5174/dashboard and tap Classic / Modern / Compact.
